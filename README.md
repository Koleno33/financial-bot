# Financial Bot
Текстовый Telegram-бот для учета доходов и расходов.

Основная цель — создать удобного персонального помощника, который не будет перегружен ИИ-технологиями и может быть легко развернут на личном сервере.

Взаимодействие с ботом также реализовано максимально просто, засчёт ввода простых текстовых фраз на ограниченном естественном языке.

## Возможности
- Есть механизм разделения на разные валюты. Можно указывать какие угодно валюты. Бот будет подсчитывать статистику по доходам/расходам для каждой валюты отдельно.
- Также есть механизм разделения на разделы. Это может быть один раздел, если вы не разделяете источники трат/прибыли, а могут быть разные. Например, раздел `работа` и раздел `подработка`.
- Для каждого раздела и валюты пользователь может сам добавить синонимы так, как ему удобно их называть. Отсюда получаем возможности обращаться к валюте `рубль` как `руб` или же к разделу `покупки` как `магазин`.
- Для каждой записи может быть добавлен комментарий.
- Есть также функционал создания отчета в форме Excel документа, который будет прислан ботом лично вам, без всяких Google Sheets.

## Пример использования
Все эти возможности реализованы в рамках простейших фраз для управления ботом. Вот примеры таких фраз.

Добавление дохода:
```
100000 руб зарплата
```
Бот запишет этот доход в раздел с именем `зарплата` на текущий момент.
То есть нет необходимости каждый раз вспоминать, какое сегодня число и смотреть какое сейчас время.

Но можно и уточнить при желании, например, добавив расход (отличается наличием знака минуса):
```
вчера 17.00 -150 руб еда ужин
```
Тут будет создана запись на указанное время вчерашнего дня в разделе `еда`, а также указан комментарий, который идёт всегда в самом конце.

Таким образом, общий формат добавления записи таков:
```
[дата] [время] сумма валюта раздел [комментарий]
```
Дата, время, комментарий не являются обязательными.

С просмотром всё так же просто:
- можно просмотреть расходы в определенном разделе: `расход еда`;
- можно просмотреть разницу доходов и расходов: `дельта август 2025`;

Подробнее особенности работы можно узнать, если ознакомиться со справкой при команде `/start`.

## Реализация
Основные зависимости:
- `Telethon` для взаимодействия с API Telegram;
- `SQLAlchemy` для взаимодействия с локальной SQLite БД;
- `openpyxl` для формирования Excel отчёта;

## Запуск
Для запуска потребуется:
- Telegram-бот и его токен, а также ваши Telegram API ID и API HASH;
- конфигурационный файл;
- виртуальная среда Python.

Конфигурационный файл выглядит следующим образом:
``` json
{
  "bot_token": "your_bot_token",
  "api_id": "your_api_id",
  "api_hash": "your_api_hash"
}
```
Его необходимо создать, ввести данные и сохранить с именем `config.json`.

Шаги по запуску для ОС Linux (в директории склонированного репозитория):
``` bash
python -m venv .
source bin/activate
pip install -r requirements.txt
python bot.py
```
При желании данные действия могут быть вынесены в `Dockerfile`, а сам бот изолирован в Docker-контейнере.
